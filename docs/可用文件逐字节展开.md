我按「相机原片 tier=1」推断「相机要 High tier」，结果把能播的配置改成不能播的。

### 2.1 从这张表里能直接读出来的结论

**（a）硬不变量（10 个文件全一致，改了就废）**

```
ftyp major_brand = "qt  "        ftyp minor_version = 538315008
视频轨有 edts/elst，音频轨没有 edts
音频 mdhd.timescale = 48000，音频没有 stss
音频每块样本数 = 24024（= 0.5 秒 @48kHz）
NCDT 子盒顺序 = NCHD NCTG NCTH NCVW NCM1 NCM2 NCDB
```

**（b）分块规则 = 每 0.5 秒一块（看 `视频stsc` / `音频stsc` 两行）**

```
59.94 帧率（时基 60000）: 视频每块 30 帧  音频每块 24024 样本
29.97 帧率（时基 30000）: 视频每块 15 帧  音频每块 24024 样本   <- 相机 DSC_8960 铁证
```

**（c）★ 值得注意的模式：6 个能播的工具产出，`tkhd.duration` 全是 228228 / 228220**

也就是**模板 DSC_8955 的原始值，从来没被改过**：

```
DSC_4470  视频时长 10.20 s   tkhd.duration = 228228 (= 3.80 s)  能播
DSC_4496  视频时长 10.01 s   tkhd.duration = 228228            能播
DSC_4500  视频时长  8.01 s   tkhd.duration = 228228            能播
DSC_4512  视频时长 254.70 s  tkhd.duration = 228228            能播
DSC_4521  视频时长 254.70 s  tkhd.duration = 228228            能播且快进正常
相机原片  各自正确值                                            能播
```

**相机自己的文件写的是正确值，我的能播文件写的都是错的** —— 两边都能播，
所以 `tkhd.duration` **不是硬判据**；但它是我所有能播文件唯一的共同点，
而后续改动（写成正确值）的文件全部失败。**这条要单独做实验验证，不要凭它下结论。**

**（d）帧率相关的字段（随输出帧率变）**

