# 测试指引 · v0.1.0-beta.3

本版把界面整个重做了（批量 / 合并 / 分片，没有高级模式），另外修掉一个 29.97 长片的音频分块 bug。
请按下面四步走，重点看**相机里能不能播**。

## 第 0 步：解压与放置

- 下 `video-to-camera-mov-v0.1.0-beta.3-win64.zip`，解压到**桌面或 D 盘**这类普通目录；
  不要放 `C:\Program Files`（程序要在自己旁边写中间文件）。
- 双击「相机视频转换器.exe」应直接出现窗口（不需要装 Python / ffmpeg）。

## 第 1 步：看界面顺不顺手

1. 点「选择视频」，多选两三个文件 → 列表里会多出几行，输出名自动接 `DSC_####`。
2. 点「合并视频」页签 → 「添加分片…」→ 选一个 `.m4s` 视频分片，看是否自动配到同名音频（列表显示 `xxx.m4s +音频`）。
3. 点「更多选项 ▾」，确认模板 / 封面 / 分段三行能出来；点「日志 ▾」确认日志能展开收起。
4. 什么都不点，直接双击 `自检.cmd`（把一段短视频拖上去），三步自动跑完并生成三个报告文件。

## 第 2 步：转一段短视频

1. 选一个 **10 秒以内**的小视频 → 画质选「小体积 · 5 Mbps」→ 勾上「转换完自动校验」→「开始转换」。
2. 期望：状态行显示进度与「×倍速 · 剩 MM:SS」，完成后该行变成「完成 · 43/43」，
   底部出现「打开文件夹 / 拷到相机卡」，日志里能看到 `=== 结论：43 项通过，0 项未通过`。

## 第 3 步：拷到卡上，在相机里验证（最重要）

把转好的 `.MOV` 拷到 `F:\DCIM\101NZ5_2\`（文件名保持 `DSC_####`），拔出再插入，然后：

- [ ] 相机缩略图里能看到它，封面不是黑块/白块
- [ ] 能播放，画面和声音都正常
- [ ] 时长显示正确（和电脑上一致）
- [ ] 能完整播完，不卡死、不黑屏
- [ ] 快进越过结尾时会**停住**（夹紧），而不是跳回文件开头

## 第 4 步：回传

请把这些发回：`smoke-report-ui.txt`、`v3-59.txt`、`v3-30.txt`，以及上面 5 个勾选的实际情况
（哪一条不满足、文件多长、相机什么提示）。

> 注意：`smoke-out`、`smoke-out-batch` 里是自检产生的临时文件，**不要**拷到卡上，
> 它们的文件名是 `SMOKE_DSC_9001.MOV` 这种，相机不认。
