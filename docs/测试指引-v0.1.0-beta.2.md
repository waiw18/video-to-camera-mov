# 相机视频转换器 v0.1.0-beta.2 —— 测试指引（一页）

## 这是什么
把普通视频（mp4 / mov / mkv / avi / ts / flv / webm）转成**尼康相机能认的 MOV**：
1920×1080 / H.265(x265) / PCM 24bit，容器结构、参数集、缩略图都按相机原生格式写。
输出帧率可选 **59.94**（相机原生）或**跟随源**（29.97/30fps 的源保持原速，快约一倍）。
转完会**自动跑 43 项门禁校验**，全过才建议拷到卡上。

## 一、准备（干净机器也只要这一步）
1. 解压下载到的那个 zip（`…v0.1.0-beta.2-win64.zip`），得到「相机视频转换器」文件夹，
   放到**桌面或 D 盘任意普通目录**；别放 `C:\Program Files`（程序要在自己旁边写临时文件）。
2. 这台机器**不需要**装 Python 或 ffmpeg，都打进去了；文件夹约 400 MB。
3. 第一次双击 exe 若提示"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**
   （测试版没做代码签名，属正常）。

## 二、先跑自检（约 2 分钟，确认这台机器能不能用）
把**相机卡里的一段视频**（建议 10 秒以内，转得快）**拖到 `自检.cmd` 上**松手。
- 会弹黑窗口依次跑三步：**界面自检** → **完整流程 59.94** → **完整流程「跟随源」**，
  跑完前别关窗口；
- 结束后同目录出现 `smoke-report-ui.txt`、`smoke-report.txt`（59.94）和
  `smoke-report-src.txt`（跟随源）；
- 打开这两个 smoke 报告，前几行 **结果 = 成功**、**门禁通过: True** 就说明这台机器没问题；
  第 8 行 `实际参数` 是程序真正传给转换核心的参数，出问题时它最有说服力；
- 源不是 29.97/30fps 时，第三步会自动退回 59.94 再转一遍（无害，只是多花时间，可以跳过）；
- 不是"成功"→ 把这三个 txt 发回给我。

## 三、再用界面走一遍（这才是给普通用户看的样子）
1. 双击 **相机视频转换器.exe**；
2. 「输入文件」选一个视频；「输出目录」默认 `我的视频\相机转换输出`，可改；
3. 「输出文件名」按相机编号填，例如 `DSC_4600.MOV`（**别和卡上已有文件重名**）；
4. **新**：「输出帧率」按源来选 —— 源是 29.97/30fps 就选「跟随源」（模板会自动换成 29.97 那张）；
5. 点 **① 开始转换** —— 看进度条、预计剩余时间、下方日志；
6. 转完自动跑门禁，进度框显示「**门禁 43/43 通过，可以拷到卡上**」；
7. 插上相机卡，点 **③ 拷到卡上**（工具会自动找到卡上的 `DCIM` 目录并做逐字节校验）。

## 四、请重点看这几件事
- [ ] 窗口能正常打开；普通模式一屏能看全；高级模式每项都能改
- [ ] **输出帧率两项都试一次**：59.94 与「跟随源」；报告/日志里的模板名应分别变成
      `DSC_8955.MOV`（59.94）与 `DSC_8960.MOV`（29.97），输出文件的帧率分别是
      60000/1001 与 30000/1001（`实际参数` 那一行会写明有没有传 `--fps source`）
- [ ] 进度百分比会动、预计剩余时间大致靠谱（编码占 97% 时间，本来就不会走得很快）
- [ ] 转换中点「取消转换」能停下来，中间文件被清理
- [ ] 日志区有输出；「保存…」能把日志存成 txt
- [ ] 缩略图三种都试一下（首帧 / 指定时间 / 图片文件）；相机列表与全屏预览里的画面是对的
- [ ] **最关键**：转出来的文件在相机里**能播、能快进、能看缩略图**，时长对、音视频同步

## 五、出问题怎么回传
1. 点日志区右上角 **保存…**，存成 txt；
2. 附上相机上的现象（黑屏 / 文件不认 / 卡顿 / 缩略图不对 / 快进越界卡死）；
3. 告诉我**原视频**和**输出文件**的名字、时长；相机不认时最好连输出文件一起发我。

## 六、已知限制（不是 bug）
- **码率**：预设 15 Mbps 是推荐值，**5 Mbps 也已真机验证可播**（DSC_8965，43/43 门禁），
  40 Mbps 画质更好但更慢更大。早先"8 Mbps 相机不认"的记录**已作废**（没有产物或日志留存）；
- 只放开 **1080p** 两档输出（59.94 / 29.97），4K 模板没做；
- 源是 **23.976fps** 时会按 29.97 输出（补帧 +25%），源是 29.97/30 则建议选「跟随源」；
- 截取出来的**短片**在相机上快进越界时是否被夹紧**不稳定**（`DSC_9710.MOV` 只有 5 秒也能夹紧，
  更早的短片则不能，原因还没查清）——正式使用请传**全长文件**，不建议截取；
- 长片（20 分钟以上）要选"有画面"的缩略图时，容器头会超出模板的固定偏移，
  工具会自动抬高 `mdat` 到相机的 128 KiB 对齐边界（已真机验证：`DSC_9710.MOV` 能播、快进能夹紧）；
- `smoke-out` / `自检输出` 这类自检目录是临时产物，**别拷到卡上**；
- 单文件版首次启动慢（要解包到临时目录），测试请用**文件夹版**。
