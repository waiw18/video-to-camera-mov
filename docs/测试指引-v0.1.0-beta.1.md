# 相机视频转换器 v0.1.0-beta.1 —— 测试指引（一页）

## 这是什么
把普通视频（mp4 / mov / mkv / avi / ts / flv / webm）转成**尼康相机能认的 MOV**：
1920×1080 / 59.94fps / H.265(x265) / PCM 24bit，容器结构、参数集、缩略图都按相机原生格式写。
转完会**自动跑 43 项门禁校验**，全过才建议拷到卡上。

## 一、准备（干净机器也只要这一步）
1. 解压下载到的那个 zip（`…v0.1.0-beta.1-win64.zip`），得到「相机视频转换器」文件夹，
   放到**桌面或 D 盘任意普通目录**；别放 `C:\Program Files`（程序要在自己旁边写临时文件）。
2. 这台机器**不需要**装 Python 或 ffmpeg，都打进去了；文件夹约 400 MB。
3. 第一次双击 exe 若提示"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**
   （测试版没做代码签名，属正常）。

## 二、先跑自检（约 30 秒，确认这台机器能不能用）
把**相机卡里的一段视频**（建议 10 秒以内，转得快）**拖到 `自检.cmd` 上**松手。
- 会弹黑窗口依次跑「界面自检」和「完整流程（转换 + 43 项门禁）」，跑完前别关窗口；
- 结束后同目录出现 `smoke-report-ui.txt` 和 `smoke-report.txt`；
- 打开 `smoke-report.txt`，前几行 **结果 = 成功**、**门禁通过: True** 就说明这台机器没问题；
- 不是"成功"→ 把这两个 txt 发回给我。

## 三、再用界面走一遍（这才是给普通用户看的样子）
1. 双击 **相机视频转换器.exe**；
2. 「输入文件」选一个视频；「输出目录」默认 `我的视频\相机转换输出`，可改；
3. 「输出文件名」按相机编号填，例如 `DSC_4600.MOV`（**别和卡上已有文件重名**）；
4. 点 **① 开始转换** —— 看进度条、预计剩余时间、下方日志；
5. 转完自动跑门禁，进度框显示「**门禁 43/43 通过，可以拷到卡上**」；
6. 插上相机卡，点 **③ 拷到卡上**，选卡上的 `DCIM\100NZ5_2` 目录。

## 四、请重点看这几件事
- [ ] 窗口能正常打开；普通模式一屏能看全；高级模式每项都能改
      （标「已锁定」的四项：编码器 x265、并行段数 1、mdat、分辨率/帧率 —— 是**故意不给改**的）
- [ ] 进度百分比会动、预计剩余时间大致靠谱（编码占 97% 时间，本来就不会走得很快）
- [ ] 转换中点「取消转换」能停下来，中间文件被清理
- [ ] 日志区有输出；「保存…」能把日志存成 txt
- [ ] 缩略图默认取视频首帧；相机列表/全屏预览里的画面是对的
- [ ] **最关键**：转出来的文件在相机里**能播、能快进、能看缩略图**

## 五、出问题怎么回传
1. 点日志区右上角 **保存…**，存成 txt；
2. 附上相机上的现象（黑屏 / 文件不认 / 卡顿 / 缩略图不对 / 快进越界卡死）；
3. 告诉我**原视频**和**输出文件**的名字、时长；相机不认时最好连输出文件一起发我。

## 六、已知限制（不是 bug）
- **码率**：预设 15 Mbps 是推荐值；**5 Mbps 也已真机验证可播**（2026-10-07，DSC_8965）。
  早先"8 Mbps 相机不认"的记录**已作废**：那次没有留下产物或日志，原因至今未查清，
  之后再没复现过；本版预设只保留 15M / 40M 是保守选择，不是"低于 15M 就播不了"；
- 本版只支持 **1080p 59.94** 这一档输出，4K 模板没放开；
- 源视频是 29.97 / 30fps 时会被**补帧到 59.94**，转换时间翻倍；
- 截取出来的**短片（<1 分钟）**在相机上快进越界时不会被夹紧，全长文件正常 —— 本版不建议截取；
- `smoke-out` / `自检输出` 这类自检目录是临时产物，**别拷到卡上**；
- 单文件版首次启动慢（要解包到临时目录），测试请用**文件夹版**。
